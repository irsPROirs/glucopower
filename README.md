# GlucoPower 1.21

Передача глюкозы с Android в поле **каденса** или **ЧСС** велокомпьютера по BLE.
Один профиль работает за раз. Преобразование всегда ×10: 8,4 ммоль/л → 84.
Это значения глюкозы, а не реальные пульс или частота педалирования.

## Использование

1. Разрешите доступ к устройствам поблизости и уведомлениям.
2. Включите локальную трансляцию в xDrip+ или GlucoDataHandler.
3. Выберите Каденс либо ЧСС и нажмите «Начать вещание».
4. Добавьте датчик через поиск на велокомпьютере. Для завершения нажмите «Остановить».

В меню «Тесты» доступны только **каденс 65 об/мин** и **ЧСС 55**.
Тест не заменяет сохранённую глюкозу. Для возврата к реальным данным выберите
профиль на главном экране и снова нажмите «Начать вещание».
Диагностика и рекомендации по фоновой работе доступны в меню.

Если CC600 сохраняет датчик, но не получает данные, удалите прежнее сопряжение
CC600 ↔ телефон и добавьте датчик через поиск CC600. Пользователь подтвердил,
что это восстановило ЧСС и каденс на vivo в версии 1.15.

## Версия 1.21

- Удалены мощность/CPS, тестовые варианты рекламы A–F, VPM и переключатели имени/UUID.
- Удалён множитель: оба профиля всегда передают глюкозу ×10.
- CSC 1816 / 2A5B: Read + Notify, CCCD; только обороты шатуна, без скорости колеса.
- Исправлена начальная временная метка виртуального каденса; счётчики 16-битные.
- Сохранены синий адаптивный интерфейс, фоновый сервис и очередь уведомлений.
- Старые настройки рекламы удаляются; сохранённая мощность переходит на каденс.

## Сборка

JDK 17, Android SDK 36, Build Tools 36.0.0. Из корня проекта:

```text
./gradlew assembleDebug testDebugUnitTest lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Сборка не подтверждает совместимость конкретного телефона и велокомпьютера.
