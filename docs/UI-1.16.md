# Интерфейс 1.16

Проверка 20 октября 2026: assembleDebug, testDebugUnitTest, lintDebug успешны.
70 тестов, включая запуск MainActivity с Material-темой и проверку главных
действий/сохранения профиля. Lint: 0 ошибок, 24 предупреждения.
APK 1.16 (code 17) подписан тем же сертификатом, что 1.15; apksigner verify
успешен. SHA-256: `4C16C350786C1A7AF9E72F7D704D821577E9975219C0242C637EFDFDF941184C`.
На физическом телефоне новый интерфейс в рамках этой работы не проверялся.

Главный экран: карточка последней глюкозы, источник и время, выбор Каденс/ЧСС,
статус подписки, «Начать вещание» и «Остановить». Выбор профиля сохраняется и
применяется только по нажатию запуска. Главный запуск всегда выбирает реальные
данные, даже если предыдущая сессия была тестовой.

Меню приложения:
* Тесты и настройки: тест каденса 93, тест ЧСС 93, множитель и параметры рекламы.
* Диагностика: полный журнал с копированием.
* Работа в фоне: управление исключением из оптимизации батареи.

Использована `com.google.android.material:material:1.14.0` и
`Theme.Material3Expressive.DayNight.NoActionBar`: настоящие Material-компоненты
на Views, без миграции BLE на Compose. Источник возможностей:
https://github.com/material-components/material-components-android/releases/tag/1.14.0

MainActivity вынесена в отдельный файл. Сервис добавляет только поля running/mode
к UI broadcast. Протоколы CSC/HRS, очереди, сохранение подписок и настройки
рекламы сохранены. Разрешения запрашиваются перед запуском с продолжением после
ответа; отказ в уведомлениях не блокирует BLE при выданных Bluetooth-разрешениях.

При начале работы обнаружен незавершённый merge с прежней реализацией мощности.
Для сервисного файла сохранена сторона текущей версии 1.15 (index stage 2),
добавлены только изменения представления. Исходный конфликтный файл сохранён
локально в `.tools/ui-pre-merge.kt.txt`. Workflow и изменения документов сохранены.
