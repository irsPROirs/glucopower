# 1.15: вместо мощности — BLE-каденс

Сборка `assembleDebug testDebugUnitTest lintDebug --offline` успешна.
69 тестов прошли, lint без ошибок. APK `GlucoPower-1.15-debug.apk`, code 16;
подпись проверена и совпадает с 1.14. Физический CC600 ещё не проверялся.

По просьбе пользователя профиль CPS заменён на CSC, режимы ЧСС сохранены.
Имя приложения и applicationId сохранены для установки поверх предыдущей версии.

* Primary service 1816, Measurement 2A5B NOTIFY + CCCD 2902 READ/WRITE.
* Feature 2A5C READ: 02 00 (только Crank Revolution Data).
* Sensor Location 2A5D READ: 05 (left crank).
* Нет колёсных данных, нескольких расположений или Control Point.
* Measurement 5 байт: flags 02, crank revolutions uint16 LE,
  last crank event time uint16 LE в единицах 1/1024 секунды.

Основание: [Bluetooth SIG CSCS 1.0](https://www.bluetooth.com/wp-content/uploads/Files/Specification/HTML/CSCS_v1.0/out/en/index-en.html),
разделы 3.1.1.3 и 3.4. Для выбранных возможностей Control Point исключён.

CadenceEncoder интегрирует заданные об/мин по SystemClock.elapsedRealtime;
время последнего полного оборота вычисляется с учётом дробного остатка.
Счётчики оборачиваются по 16 бит. Без оборота event time не меняется.
При смене темпа прошедший интервал относится к предыдущему темпу.
При перезапуске GATT генератор сбрасывается, при повторных пакетах с тем же
временем не создаёт лишних оборотов. Это виртуальный каденс для отображения
глюкозы, не измеренные движения человека.

При ×10: 9,3 ммоль/л → 93 об/мин. Без ×10 значение округляется до целого.
Тест выдаёт 93 об/мин независимо от глюкозы. Первое уведомление — исходные
счётчики, приёмнику нужны следующие события для расчёта. Возможны задержка
и сглаживание отображения велокомпьютером.

Сохранённые POWER/POWER_TEST мигрируют в CADENCE/CADENCE_TEST. Старые CPS
подписки не переносятся в CSC: ключ подписки включает UUID сервиса и измерения.
Структура рекламы 1.14 сохранена; меняется UUID на 1816. ЧСС не изменена.

Аппаратная совместимость CSC с CC600 на vivo ещё не проверена. Для проверки
выбрать тест каденса 93, удалить только старую запись тестового телефона на
CC600 и выполнить поиск. В nRF Connect подписываться на 2A5B: ожидаются
изменяющиеся счётчики, а не буквальные байты числа 93.
