# GlucoPower 1.18: сравнение рекламных пакетов

Пользователь подтвердил: после удаления сопряжения мощность по-прежнему не обнаруживается. Это не исправлено и не объясняется только старой парой.

Меню «Тесты и настройки» → «Пакет» выбирает один вариант. Затем нажать «Тест мощности · 93 Вт». Выбор сам не перезапускает радио. A–F имеют приоритет над тремя прежними переключателями. «0» возвращает прежнее поведение. Настройка применяется и к другим профилям, но для сравнения оставлять POWER_TEST.

| Вариант | ADV | Scan response | Интервал |
|---|---|---|---|
| 0 | Прежние настройки | Прежние настройки | Прежний |
| A | UUID1818 | Нет | LOW_LATENCY |
| B | UUID1818 | Имя | LOW_LATENCY |
| C | UUID1818+имя | Нет | LOW_LATENCY |
| D | Только системные поля | UUID1818+имя | LOW_LATENCY |
| E | UUID1818+Service Data1818 без payload | Имя | LOW_LATENCY |
| F | Как B | Имя | BALANCED (~250мс, фактический интервал зависит от стека) |

A–F: legacy/connectable, без таймаута; TX MEDIUM, поле TX в пакет не добавляется. Имя системное; слишком длинное имя вызывает понятную ошибку, а не скрытое изменение схемы. C максимум22 UTF-8байта; B/E/F29; D25. Пустой Service Data E — диагностическая проверка наличия UUID в AD16, не измерение CPS и не Appearance. D проверяет активное сканирование; при пассивном сканировании ожидаемо может не обнаруживаться.

Flags и Appearance не управляются: публичный Android API не поддерживает произвольные AD01/AD19. Это ограничение показано в меню/журнале. Никакой подмены производителя или притворного Appearance нет. UUID, имя, Service Data отражены в журнале; фактические байты эфира подтверждаются nRF/HCI, а не только callback Android.

Порядок: остановить вещание → выбрать A → тест мощности93 → поиск CC60060сек → сохранить диагностику и результат. Повторить B–F. Если датчик нашёлся, проверить показания93 и отметить, виден ли он как мощность. После успешного добавления удалить именно тестовую запись перед следующим вариантом, иначе кэш CC600 может исказить сравнение. Не менять профиль, имя телефона или сопряжение посреди одной попытки. Второй телефон может сканировать, но не подключаться. Отметить отдельно: найден / подключён / показания93. ВариантB можно проверить с тестомЧСС как контроль работоспособности радио.

Исходный рабочий механизм GATT/CCCD/уведомлений не изменён. Физическая совместимость новых вариантов ещё не проверена.
