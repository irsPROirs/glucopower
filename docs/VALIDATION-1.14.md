## Изменение

Добавлен включённый по умолчанию переключатель рекламы VPM. Он имеет приоритет
над прежними двумя настройками; выключение возвращает их сохранённые значения.
В обоих профилях применяется один legacy connectable пакет: UUID выбранного
сервиса + имя адаптера + TX power AD-поле. Scan response не передаётся.
LOW_LATENCY, timeout 0, мощность передатчика по умолчанию Android (MEDIUM).
Настройка воспроизводит проверенный путь VPM, не его GATT-профиль с колесом.

Имя ограничено 19 байтами UTF-8: flags 3 + UUID16 4 + TX power 3 + name header 2
+ имя <=31. Длинное/пустое имя даёт понятную ошибку до запуска; системное имя
приложение не меняет. При необходимости пользователь задаёт короткое имя
Bluetooth, например GlucoPower. Запуск после регистрации всех сервисов,
CCCD, очередь уведомлений и четыре режима данных сохранены.

Это эксперимент совместимости, **не подтверждённое исправление CC600**.
Не добавлены фиктивные обороты колеса, Control Point или принудительная
подписка. Не объединены с этим экспериментом задержки перезапуска и новые
HRS-атрибуты — иначе результат невозможно отнести к конкретному изменению.
